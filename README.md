# Firebase Todo List App

Flutter와 Firebase Cloud Firestore를 이용한 할 일 관리 앱입니다.

## 주요 기능

- 할 일 추가 및 수정
- 할 일 삭제
- 삭제한 할 일 복원
- Firestore 실시간 데이터 동기화

## 사용 기술

- Flutter / Dart
- Firebase Cloud Firestore
- GetX
- Flutter Slidable

## 실행 방법

```bash
flutter pub get
flutter run
```

Android 환경을 기준으로 제작했습니다.
